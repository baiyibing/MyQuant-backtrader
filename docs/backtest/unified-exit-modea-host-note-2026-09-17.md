**Top 5**：全部 r2（止盈 5–7% × 止损 10%/无 × N=10）：+1.50% / +1.40% / +1.37% / +1.36% / +1.28%；top20 内 19 组 r2 + 1 组 r3 trailing（#17 `r3_y10_n10` +0.97%）。冠军族 X∈{5,7,10}×Y∈{5,10,∞}×N∈{8,10} 是宽平台（见稳健性②）。

**稳健性四件套**：

1. **半窗**：top20 名单交集 = **0**——h1 偏好长持有/无止损（h1 top1 是 `r1_n20`），h2 偏好紧止损（y5 族）。但**全窗冠军族在两半窗均处前排**（`r2_x7_yinf_n10` 进 h1 top3；`r2_x7_y7_n10` 进 h2 top4）。结论口径：**族稳、精确名次不稳**，参数选择应报族不报点。
2. **平台性**：top20 的 r2 单元**无孤峰**（neighbor_gap ≤ ±0.24%，冠军邻域甚至略优 +0.09%）。过拟合红旗未亮。
3. **分层**：创业板每实例均收益 0.63% vs 主板 0.29%；按月 5 正 7 负（最差 202607 −3.5%、最好 202604 +3.1%）——市况依赖明显，与半窗结果互证。
4. **次日开盘买**：top 组换开盘买入后 +2.2%~+2.6%，**高于**收盘买入的 +1.3%~+1.5%——收盘买入的「前视偏高」担忧**解除**（反向前视：名单日盘中冲高、收盘买更贵），且暗示买入时点本身有优化空间。

## 3. 研究结论（模式 A）

1. **名单池子整体强下行**（持有到期末 −24.4%）；全部 280 组统一离场规则都在「减亏」，最好的也只 +1.5%。
2. **统一固定参数规则离上界极远**：冠军 +1.5% vs oracle +129.6%，提取率 ≈ 1.2%。「逼近全局最大收益」的目标下，固定网格远未到顶——条件化规则（第二阶段+）与模式 B 盘中触发的边际价值有量化依据。
3. 可用的正面结果：冠军族在 11 亿基数上 +1.5%（年化口径 ≈ +1.7%）、回撤 <2.5%、胜率 ~51%——作为「池子对冲成本」的基准锚，不是「收益策略」。

## 4. Nits（转 Codex 后续票，不挡结论）

- **plateau 覆盖缺口**：`neighborhood_plateau_flags` 只解析 `r2_*` 标签，top20 里的 r3（#17）不查孤峰。
- **性能**：72 分钟单核。py-spy 定位热点 `date_to_ymd` / `_bar_close_map`（纯 Python 日期转换在每策略×每日×每股热循环内）。向量化（`index.strftime` 预转缓存）+ half-windows 复用主聚合的净值增量，可到分钟级。模式 B 之前值得先做。
- 99 笔超幅度样本引擎已保守跳过；提案 §十一「核对是否新股/复牌」待办降级为存档（不影响入场集恒定性）。
