```
止损 20%（T+1 起；无 giveback）
```

## 6. 单测向量（批准实施后要绿）

1. `n_days=1`、现价 −20% → 止损；同日峰值再高也不止盈。
2. `n_days=3`、峰值 +40%、现价已破档位线 → **不**止盈。
3. `n_days=4`、峰值 +4%、线 = max(1.01×成本, 成本+30%×涨幅) → 触线卖；未触持有。
4. `n_days=4`、峰值 +7% / +12% / +20% / +40% → 分别按 max(×1.02, 保留 30%) / max(×1.04, 保留 30%) / max(×1.10, 保留 60%) / max(×1.15, 保留 60%)。
5. 峰值 +3%（含）不评档位；峰值 +6% 走 max(×1.02, 保留 30%)。
6. 满 20 日从未到 +6% → stale；`n_days=19` 未武装不因僵持卖。
7. 已持再出现在名单 → `skip_held`，不加第二笔。
