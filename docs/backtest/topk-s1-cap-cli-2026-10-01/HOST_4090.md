## 5. STATUS 五字段

脚手架写 `STATUS.json`，仅五字段：

```json
{"status":"NOT_RUN","stage":"handoff","reason":"awaiting host inputs","tip":"待核对 PR 完整 SHA","out_dir":"本次外部输出绝对路径"}
```

- `OK`：两臂完成且源 hash 前后相同；不是 certified、不是 SSOT green。
- `INPUT_BLOCKED`：分数/单位/PIN/覆盖/代码干净条件等未满足，未启动两臂。
- `FAILED`：模拟、写出或运行后 hash 检查失败，可能有部分产物，不能当成功结果。
- `NOT_RUN`：尚未执行，或 prepare-only 已完成。开始拉取前的状态也用此值。

若脚手架启动前就缺 pred/解释器/权限，4090bot 手填同样五字段及具体原因；
out-dir 已存在/重叠输入时脚手架拒绝写任何文件，另用全新回执位置报告。
`no_ssot_compare_authorization`、不自动合并的边界保持。
