## 2. 归档 stop10 规则（原文口径）

```
止损 10%（T+1 起；与 giveback 买价×0.90 对齐）
T+1 只评止损；T+2 起评止盈
(0,6%)     保留涨幅 30%，且现价 ≥ 买价×1.01
[6%,15%)   买价×1.02
[15%,50%]  max(买价×1.15, 保留涨幅 60%)
(50%,100%] 保留 70%
>100%      保留 80%
满 20 日且从未到 +6% → stale
只加赢家（现价低于任一未平成本则不加）
上证十日线两日下方停开新仓，已持可加
每码 100 万整笔
```

和本包的关键差：

| | 本包 stop6 | 归档 stop10 |
|---|---|---|
| 止损 | 6% | **10%** |
| 加仓 | 名单再现即加（含输家） | **只加赢家**（现价 ≥ 各笔成本） |
| 档 1 | &lt;3% 不评；≥3% max(×1.01, keep30) | 全程 keep30 且 ×1.01（无死区） |
| 档 2 | max(×1.02/1.03@9%, keep30) | **只 ×1.02** |
| 档 3 | max(×1.10/1.15@30%, keep60) | **max(×1.15, keep60)** |
| 档 4 | max(×1.35/1.50@70%, keep50) | **keep70，无保底** |
| 档 5 | keep70 | **keep80** |

买价 10、档 2 峰 11.40（+14%）：本包线 10.42，stop10 线 **10.20**——本包更早下车，进不了 +15%。档 3 峰 12（+20%）：本包 11.20，stop10 **11.50**——stop10 档 3 锁得更紧、中位更高。
