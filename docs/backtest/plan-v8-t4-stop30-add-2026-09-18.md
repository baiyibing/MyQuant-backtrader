## 3. 批准实施后的完整卖点

```
止损 30%（T+1 起；无 giveback）
T+4 起评止盈（n_days≥4）；T+1～T+3 只评止损
(0,3%]      不评档位
(3%,6%)     max(买价×1.005, 买价+30%×涨幅)
[6%,9%)     max(买价×1.01, 买价+30%×涨幅)
[9%,15%)    max(买价×1.03, 买价+30%×涨幅)
[15%,30%)   max(买价×1.07, 买价+50%×涨幅)
[30%,50%)   max(买价×1.14, 买价+50%×涨幅)
[50%,100%)  买价+60%×涨幅
[100%,∞)    买价+70%×涨幅
分钟回撤须距峰值 ≥15 分钟
满 20 日且峰值从未到 +6% → force_sell:stale
已持再进名单可加仓（不看输赢）；每笔 100 万
上证十日线两日下方：当日新开与加仓都不做
```

`px<cost` 仍不评档位回撤。止损在引擎里先于止盈。各 lot 独立评卖点。

## 6. 单测向量（批准实施后要绿）

1. `n_days=1`、现价 −30% → 止损；同日峰值再高也不止盈。−20% **不**止损。
2. `n_days=3`、峰值已破档位线 → **不**止盈。
3. `n_days=4`、峰值 +4% / +7% / +12% / +20% / +40% → 分别按 §3 的 `max(...)` 触线卖。
4. 峰值 +3%（含）不评档位；峰值 +6% 走 `max(×1.01, 保留 30%)`。
5. 峰值 +50% 走保留 60%；峰值 +100% 走保留 70%。
6. 满 20 日从未到 +6% → stale；`n_days=19` 未武装不因僵持卖。
7. 已持再出现在名单、现价低于成本 → **加**第二笔，不记 `skip_add_loser`。
