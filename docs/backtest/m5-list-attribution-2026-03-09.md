| 对照 | 对齐天数 | ∩=0 的天数 | 非零日 | 日均 \|∩\| |

| pred ∩ hand | 129 | **129** | 无 | 0 |

按月：202603–202609 每月对齐日 pred∩hand 与 pred∩hand10 均为空。重叠度不随窗长变出交集。

名单换手（当日相对昨日新增 / 当日宽度）：pred 0.898；hand 0.984；hand10 0.988。三源都接近日更。

首轮 15 日曾有 `20260309` ∩=1（`600546`）。本轮扩展 pred 该日 Top10 与首轮 R3 pred **零交集**；冻结手工仍含 `600546`，新 pred 不含。不要把两轮 3 月名单当成同一对照。
