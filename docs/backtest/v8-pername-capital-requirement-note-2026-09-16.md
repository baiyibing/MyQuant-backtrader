# v8 per_name 资金需求实测：3 亿不够、≈5 亿峰值、6 亿下序方差归零

> **日期**：2026-09-16。**执行**：宿主本机 agent（zcode）；master `10a885f`；只读参数实验（`--cash-total`），非合入门、不改代码。
> **人裁定稿（2026-09-16）**：v8 per_name 研究标准资金 **`--cash-total 500000000`（5 亿）**；README v8 示例已同步。
> **背景**：业务问「每股 100 万上限需要多少总资金，3 亿够吗」。窗口/池/卖点与 D 烟测同（20251023–20260909、`stock_pool/`、v8 per_name 30% 止损+去武装阶梯）。

## 1. 结论

| 总资金 | skip_cash | 峰值并发持仓 | 结论 |
|-------:|----------:|-------------:|------|
| 2,100 万（D 烟测原值） | 3,972 | ~21 只 | 严重不足 |
| 3 亿 | 675 笔（6.75 亿名义排队） | 350 只 | **不够** |
| **10 亿（无约束探针）** | **0** | **495 只（2026-02-25）** | 量出真实需求 ≈ **4.95 亿** |
| **6 亿（本短记主跑）** | **0** | 495 只（占用峰 82.5%） | **够；且序方差归零** |

**推荐口径（已裁）**：`--cash-total 500000000`（5 亿）。5 亿验证跑：`skip_cash=0`，期末 470,106,602.79（-5.98% 全资金 / **动用 -0.77%** 与 6 亿跑完全一致——同一组合路径，仅少 1 亿闲置现金）；最大回撤 -13.07%（全资金口径基数不同）。峰值日实际占用 4.43 亿（2026-02-25），5 亿留余量 13%。

## 2. 6 亿主跑结果（file_order，D 烟测同窗）

- 买入 **3,894**（+追买 219）、期末仍持仓 106；`skip_cash=0`。
- 期末净值 **570,106,602.79**：总收益率（全资金）**-4.98%**、动用资金收益率 **-0.77%**、最大回撤 **-11.02%**。
- 对照 21M 口径（-28.65%）：差异主因是**组合口径变了**（21M 只买得起代码序前缀的 ~21 只小代码样本；6 亿买入全池）——两口径 NAV **不得互比**，跨口径只比 lot 级指标。

## 3. 序方差在资金充足时归零（本轮最重要发现）

file_order + `--ration seeded_shuffle --ration-seed {0,1,2,3}` 共 5 跑：

- **5 跑 NAV 完全相同**（570,106,602.79，std=0）；summary 全指标一致。
- trades.csv 原文件不同仅因**行序**（shuffle 改变当日买入遍历顺序）；按列排序后 **7,788 行逐行一致**。
- 机理：`--ration` 只在现金约束处起作用（先到先得决定谁被 skip_cash）；资金 ≥ 峰值需求时**人人有份，顺序不再筛人**。
- 推论：NP1 量出的 11pp 序方差带（[capital-ration-seed-nav-results-2026-09-16.md](capital-ration-seed-nav-results-2026-09-16.md)）是 **21M 资金稀缺口径的现象**；资金充足口径下 v8 单跑 file_order 即为确定结果，无需 seed 带宽。

## 4. 以后换窗口/池/卖点的三步定资金法

```
① --cash-total 1000000000 跑一遍 → 确认 summary skip_cash=0
② trades.csv（仅 BUY/SELL 行，按日稳定排序）累计 买入−卖出 的最大值 = 峰值并发 N
③ 资金 = N × 100万 × 1.1
```

注意：峰值是窗口内单日极值（本窗 2 月下旬），资金利用率前低后高——收益解读用「动用资金收益率」行。
