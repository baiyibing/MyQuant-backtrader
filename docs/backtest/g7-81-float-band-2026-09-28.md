## 冻结数学合同

令成本 C > 0、峰值 P > 0，r = P/C − 1。唯一分档表达式为 **lo < r ≤ hi**；小档下沿特例含等号：0.06 ≤ r ≤ 0.15。

| 峰值收益 r | 绝对收益地板 |
|---|---|
| r < 6% | 无 |
| 6% ≤ r ≤ 15% | +2% |
| 15% < r ≤ 40% | +15% |
| 40% < r ≤ 60% | +30% |
| 60% < r ≤ 80% | +50% |
| 80% < r ≤ 100% | +70% |
| 100% < r ≤ 120% | +90% |
| r > 120% | 无分档地板；最高价回撤 20% |

以下 r 的偏移 Δ = 10⁻¹²（收益比例，非价格容差）。C=10 时 P=10×(1+r)，价格偏移为 10⁻¹¹；测试直接构造 Decimal 价格，不先作浮点除法。

| 边界 r | r−Δ 地板 | 精确 r 地板 | r+Δ 地板 |
|---|---|---|---|
| 0.06 | 无 | +2% | +2% |
| 0.15 | +2% | +2% | +15% |
| 0.40 | +15% | +15% | +30% |
| 0.60 | +30% | +30% | +50% |
| 0.80 | +50% | +50% | +70% |
| 1.00 | +70% | +70% | +90% |
| 1.20 | +90% | +90% | 峰回撤 |

+60% 具体两侧价格：P=15.99999999999 / 16 / 16.00000000001，C=10，对应 +30% / +30% / +50% 地板。精确 P=16、C=10、现价 14 时应不止盈；现价 13 时返回 `trail:band:30`。

## 选择：默认 OFF 的精确分数路径

日线与共享分钟 CSV 入口新增 `--fix-s81-band-precision`，仅允许 `--strategy version8_1`（已有别名照常支持）。`run` / `simulate` / `apply_csv_strategy` / `take_profit_reason` 同名 Python 参数 `fix_s81_band_precision=True`；默认 False。开启时 stats 记录 `fix_s81_band_precision=True`，manifest 开启时也记录 CLI 参数。OFF 不添加 stats 字段、不改变旧收益计算与旧峰回撤判断；HELP_LOCK 保持原文。

失败模式：二进制浮点 `16/10-1 == 0.6000000000000001`，按严格右闭区间误入 +50% 地板，现价 14 时提前退出。不能仅把这个已受损收益转成 Decimal/Fraction 来恢复真实边界。

ON 在 `take_profit_reason` 中从**原始输入价格**构造 `Fraction(str(P)) / Fraction(str(C)) - 1`，`band_floor` 用 `Fraction(str(lo/hi))` 对比。`str` 定义本刀的十进制输入合同；Fraction 的除法及比较无 Decimal context 舍入，也没有 quantize 或 epsilon。直接调用精确 `band_floor` 时应传精确收益（例如 `Decimal('0.6')` 或 `Fraction(6,10)`）；它不会把已计算的 `0.6000000000000001` 吸附回 0.6。

120% 峰回撤的启用条件也用同一个精确 r > 1.20，避免分档与回撤臂采用两套边界。地板触发价、20% 回撤触发价、止损、撮合价格计算保持现有公式。本刀不会修复输入成本/峰值在更早的加权、除权计算中已产生的偏移；不会引入价格量化政策。

选择开关而非默认改写：8.1 是历史冻结包，边界修正会改变成交，必须继续可对照旧账。无新书注册，不改变 8/8.2–8.6。
