> **日期**：2026-09-16。名单仍是 `stock_pool/`，窗 20251023–20260909，分钟 `--cash-total 500000000`。
> **对照**：修补+上证门控+止损 6%（`_stop6`，509,622,390.51 / +1.92%）；同结构止损 30%+giveback（`_sse_ma10`，514,323,910.73 / +2.86%）。

| 旋钮 | 现锁（改前 stop6） | 已平仓形状 | 能改吗 |

| 工件 | 改法 | 净值 | 相对 stop6 |

## 3. 现锁

```
止损 10%（T+1 起；与 giveback −10% 对齐，giveback 几乎不再触发）
(0,6%)     保留涨幅 30%，且现价 ≥ 买价 ×1.01
[6%,15%)   买价 ×1.02
[15%,50%]  max(买价 ×1.15, 保留涨幅 60%)
(50%,100%] 保留 70%；>100% 保留 80%
```
