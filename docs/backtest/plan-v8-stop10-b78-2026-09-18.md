## 3. 批准实施后的完整买卖点

```
止损 10%（T+1 起）
T+1 只评止损；T+2 起评止盈
T+2 起现价 ≤ 买价×0.90 → force_sell:giveback
(0,6%)       保留涨幅 30%，且现价 ≥ 买价×1.01
[6%,15%)     买价×1.02
[15%,50%]    max(买价×1.15, 买价+60%×涨幅)
(50%,100%]   max(买价×1.35, 买价+50%×涨幅)     ← 原保留 70%
>100%        max(买价×1.60, 买价+60%×涨幅)     ← 原保留 80%
满 20 日且峰值从未到 +6% → stale
只加赢家；上证十日线两日下方停开新仓、已持可加
每码 100 万整笔
```

`px<cost` 不评档位回撤。止损在引擎里先于止盈。各 lot 独立。
