## 2. 加仓怎么加

策略 6 资金仍是 **`daily_quota`**：当日名单里的新开 + 已持加仓，一起分当天额度。新 lot **独立**成本 / 峰值 / `n_days`，自己评止损和止盈。

| 项 | 实施默认 |
|----|----------|
| 加多少 | 当日额度的一份，与新开同一套均分 |
| 名单外 | 不加 |
| 上证十日线 | 无（策略 6 本来没有） |
| 峰差 15 分钟 | **不动** |
| 止损 6% | **不动** |
| +1% 锚 / T+1..T+5+ 档 | **取消**（被两档回撤替换） |

买价 10：峰值 10.50（+5%）线 10.15；峰值 10.60（+6%）线 10.30。
