## 5. 上证闸语义核验（引擎实现口径）

`run_index_gate_cut_day`（`csv_simulate_loop.py:1600-1652`）：

- **切仓**：episode 首个 BLOCKED 日（上证连续 2 日收 MA10 下方，日前收盘状态判定）**开盘价**卖策略持仓市值一半，`price_rule=index_cut_open`，同一 episode 只切一次（latched），停泊仓不动，切掉股数按组记 memory。全运行 **1,629 笔 index_cut 全部 `index_cut_open`**。
- **回补**：闸门恢复后的首个交易日**开盘价**买回 memory 股数，**先于 pool/adds**；现金不足→部分成交、余量留 memory 次日开盘继续（分日回补）。
- 验证（2026-06 一轮）：闸门 6/08-6/12 BLOCKED → 6/15 open；回补成交价 = 当日 9:30 开盘价分毫不差（001389 6/15 182.02、300201 18.47、603629 6/16 169.66）；6/15~6/24 分日回补与停泊账日终放水金额逐日对应（265→263、210→210、168→167、107→105、25→23.5 万）；memory 按 `sorted(position_id)` 处理 → 001389（靠前）6/15 拿到现金、603629（队尾）6/16 起。
- 6.53 书 docstring「上证收复后**开盘**按记忆买回」与代码一致。**若人裁口径为「MA10 收复当日用收盘价买回」，则与引擎实现存在语义分歧，待人裁**（收复收盘确认发生于 6/12，回补在次一交易日 6/15 开盘，价亦为开盘价）。
