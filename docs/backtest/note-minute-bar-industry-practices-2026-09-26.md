## 1. 分钟线复权问题

### 1.1 数据源能力

| 数据源 | 日线复权 | 分钟线复权 | 说明 |
|--------|---------|-----------|------|
| **QMT / 迅投** | 前复权/后复权/raw 可选 | `dividend_type` 参数**可选**前/后/比率 | 本仓湖按约定存 raw，非数据源硬限 |
| **Tushare** | `adj_factor` 独立返回 | 默认 raw（可用 factor 自行调整） | factor 为日线粒度 |
| **聚宽** | 内置前复权 | 前复权（参数 `fq='pre'`） | 平台层已调 |
| **米筐 RQAlpha** | `adjust_type` 可选 | 可选 | 与聚宽同类 |
| **Qlib** | 存 raw + `factor` 列 | 同左 | **表达式层**应用因子，非存储层预调 |

**物理事实**：除权因子是日线粒度；分钟粒度 = 该日日线因子在日内均一适用。供应商不单独提供分钟因子表，但日线 factor 可直接用。

### 1.2 三种行业方案

| 方案 | 做法 | 使用者 | 优点 | 缺点 |
|------|------|--------|------|------|
| **A 全 raw** | 信号 + 成交都用 raw | VN.PY、多数 QMT 用户 | 简单 | 除权日 MA 假破、止损假触发 |
| **B 全前复权** | 日线 + 分钟调到同一域 | 聚宽、米筐 | 无域混用 | 成交价非真实市场价；容量/涨跌停判定需回 raw |
| **C 信号调/成交不调** | 信号在前复权日线算，阈值换算回 raw 域匹配分钟 | **机构实盘标准** | 信号连续 + 成交真实 | 需维护换算关系 |

### 1.3 机构为什么选 C

信号需前复权保证连续性；成交必须用 raw 真实价（容量、涨跌停、手续费依赖）。实盘天然如此——交易系统看到实时 raw 价。

### 1.4 我们现状

s12 X-01 = 方案 C 缺了换算步（前复权 MA 直接比 raw 分钟）。修复在 X-01 刀推进中。

## 2. 分钟线上的止损/止盈触发与成交

### 2.1 行业标准算法

```
对每根分钟 bar（有持仓需评止损时）：
  1. open ≤ 止损价 → 按 open 成交（跳空穿越）
  2. low ≤ 止损价 → 按止损价成交（bar 内触及，挂单假设）
  3. 两者都不满足 → 不触发
  止盈反向同理（open ≥ / high ≥）。
```

**补充规则**：
- **跌停锁定 bar**：low ≤ 止损价但该 bar 跌停封死 → 不可成交（挂到下一可交易 bar）
- **止损 vs 止盈同 bar**：保守假设止损先于止盈
- **T+1**：买入当日（T+0）不评止损（已有，不影响）

### 2.2 各平台对比

| 平台 | 触发判定 | 成交价 | 说明 |
|------|---------|--------|------|
| 聚宽 | bar H/L | 触及价或 open | 标准 |
| VN.PY | bar H/L | 触及价或 open | 标准 |
| **Backtrader** | **bar H/L** | **触及价或 open** | [orders 文档](https://www.backtrader.com/docu/order-creation-execution/order-creation-execution/)：gap-through → open 成交；H/L 穿越 → stop 价成交 |
| 我们 | **bar close** | close | **漏触发**（X-09）；另有一套在 `minute_cash_order.py` 同 close 触发 |

注：Backtrader 的 `cheat_on_close/cheat_on_open` 控制 **Market 单**在 `next()` 后何时成交，不影响 Stop 单的 H/L 触发语义。

### 2.3 我们现状的两套止损代码

| 位置 | 路径 | 触发 | 活跃条件 |
|------|------|------|---------|
| `csv_minute_backtest.py:341` | 主引擎分钟扫描 | close | 默认 |
| `minute_cash_order.py:139-142` | 时序现金引擎 | close（`px_close`） | `--fix-minute-cash-order`（X-02 开关） |
| `csv_minute_backtest_v7.py` | v7 自有会话扫描 | 各自实现 | v7 入口 |

任何止损语义开关必须**同时覆盖所有止损位**，或明确声明兼容矩阵。

## 3. 除权除息日的价格跳变

### 3.1 交易所规则

```
参考价 = (昨收 − 分红 + 配股价×配股比) ÷ (1 + 送转比 + 配股比)
参考价四舍五入到分
涨跌停 = 参考价 × (1 ± 档位)
```

补充：
- **无涨跌幅日**：新股上市首日、重新上市首日、增发上市首日等——无涨跌停限制（本仓 `limit_prices` 尚无此概念，暂不做）
- **微额除权**：交易所对任何金额的分红都调整参考价，无"噪声带"豁免

### 3.2 各平台处理

| 平台 | 做法 |
|------|------|
| 聚宽 | 内置因子，自动调整 |
| Qlib | 后复权后无跳变 |
| QMT 实盘 | 交易所直接发参考价 |
| **我们（E-R6 已落地）** | `exdiv_map.mapped_prev_close` 用日线因子比 k 缩放昨收 → 涨跌停基准。**已覆盖主路径**。 |

### 3.3 E-R6 残留缺口（本仓）

| 缺口 | 现状 | 影响 |
|------|------|------|
| **噪声带 ≤0.5% 不修正** | `exdiv_map.py:28,302-304` 有意豁免 | 微额现金分红日涨跌停差一两分钱 |
| **参考价未到分四舍五入** | `mapped_prev_close` 返回 raw×k 原始精度 | 交易所先到分再算涨跌停，本仓未做这一步 |
| **k 是因子比，非交易所精确公式** | E-R6 用日线因子比，不含配股价项 | 含配股的除权日参考价可能偏移 |
| **`exdiv=None` 路径** | version12 / `--dividend-type front` 不经过 E-R6 | 这些路径的除权日涨跌停无修正 |
