## 1. 分钟线复权问题（核心）

### 1.1 数据源现状

| 数据源 | 日线复权 | 分钟线复权 | 说明 |
|--------|---------|-----------|------|
| **QMT / 迅投** | 可选前复权/后复权/raw | **仅 raw** | 供应商不提供分钟因子表 |
| **Tushare** | `adj_factor` 独立返回 | **仅 raw** | 用户自行调整 |
| **聚宽** | 内置前复权 | **前复权**（用日线因子均一适用） | 平台层已调 |
| **米筐** | `adjust_type` 可选 | 可选 | 同聚宽 |
| **Qlib** | `qlib_bin` 后复权 | **后复权**（存储层已调） | 统一域 |

**物理限制**：除权因子是日线粒度（每日一个），分钟粒度的"因子"就是该日的日线因子在同一日内均一适用。供应商不单独提供分钟因子，但可以用户侧自行计算。

### 1.2 三种行业方案

| 方案 | 做法 | 使用者 | 优点 | 缺点 |
|------|------|--------|------|------|
| **A 全 raw** | 日线信号 + 分钟成交都用 raw | VN.PY、多数 QMT 用户 | 简单，数据源直接可用 | 除权日 MA 假破、止损假触发 |
| **B 全前复权** | 日线 + 分钟都调到同一前复权域 | 聚宽、米筐 | 无域混用问题 | 成交价非真实市场价；容量/涨跌停判定需回 raw |
| **C 信号调/成交不调** | 信号在前复权日线算，执行前把阈值**换算回 raw 域**再匹配分钟 | **机构实盘标准** | 信号连续 + 成交真实 | 需要维护换算关系 |

### 1.3 机构为什么选 C

- **信号需要连续**：前复权保证 MA/均线/止损线不因除权断裂（10 元 → 9 元的除权跌停在 raw 域看是 −10%，MA 会假死叉）
- **成交价必须是真实市场价**：容量计算（成交量 × 真实价格）、涨跌停判定（交易所用除权参考价×档位）、手续费全部依赖 raw 价格
- **实盘天然如此**：交易系统看到的是实时 raw 价格；信号引擎内部用前复权算指标，输出阈值后换算到 raw 域挂单

### 1.4 我们现状

s12 分钟版：MA 在前复权日线算（对），成交在 raw 分钟（对），但 MA 阈值**没有换算回 raw 域**就直接跟分钟 close 比——即方案 C 缺了换算这一步。这就是 X-01 critical。

## 2. 分钟线上的止损/止盈触发与成交

### 2.1 行业标准算法

```
对每根分钟 bar（有持仓需评止损时）：
  1. 检查开盘价：open ≤ 止损价 → 按 open 成交（跳空穿越，成交价劣于止损价）
  2. 检查最低价：low ≤ 止损价 → 按止损价 成交（bar 内触及，假设挂单在）
  3. 两者都不满足 → 不触发
  止盈反向同理。
```

### 2.2 关键细节

- **跳空穿越（gap-through）**：开盘直接跳过止损价 → 按开盘价成交（更差的价格），不是按止损价。这是实盘真相——集合竞价后止损单已触发但只能以更差市价成交。
- **bar 内触发用 H/L，不用 close**：bar 的 close 可能已反弹回止损价上方，只看 close 会漏触发。用 H/L 检查是否触及，触及则以止损价成交（挂单假设）。
- ** intra-bar 路径不建模**：单根 bar 内 O→H→L→C 还是 O→L→H→C 未知。标准假设：止损先于止盈（保守）；如果两者都可能触发，取止损（保守）。

### 2.3 各平台对比

| 平台 | 触发判定 | 成交价 | 说明 |
|------|---------|--------|------|
| 聚宽 | bar 的 H/L | 触及价或 open | 标准 |
| VN.PY | bar 的 H/L | 触及价或 open | 标准 |
| Backtrader | `cheat_on_close` 可选 | 默认 close（保守）；可选 open | 文档标注"cheat" |
| 我们 | **bar close** | close | **保守偏多，漏触发**（X-09） |

### 2.4 我们现状

`csv_minute_backtest.py:5` 写明"盘中触线按该分钟 close 走"；`:341` 实现为 close 触发。gap-open 已有（"开盘已跌破止损则按开盘价"）。**差异：触发条件用 close 而非 low/high**。

## 3. 除权除息日的价格跳变

### 3.1 交易所规则（实盘行为）

除权日，交易所将**前收盘价调整为除权除息参考价**：

```
参考价 = (昨收 − 分红 + 配股价格×配股比) ÷ (1 + 送转比 + 配股比)
涨跌停 = 参考价 × (1 ± 档位)
```

例：收盘 10.00，10 送 10 → 参考价 5.00 → 涨停 5.50 / 跌停 4.50（不是 11.00 / 9.00）。

### 3.2 各平台处理

| 平台 | 做法 |
|------|------|
| 聚宽 | 内置除权因子，自动调整参考价 |
| Qlib | 后复权后天然无跳变 |
| QMT 实盘 | 交易所发参考价，系统直接用 |
| VN.PY | 用户自行处理（多数不做） |
| 我们 | `market_layer.py:73-84` 用昨收直接算涨跌停——**无除权调整** |

### 3.3 我们现状

E-R6 已有除权日 cost/peak 缩放（`ashare_exdiv_economics.py`），但涨跌停参考价**没有联动**。除权日判定涨跌停会用错基准价。

## 4. 差距总表

| 问题 | 行业标准 | 我们现状 | 差距 | 对应 |
|------|---------|---------|------|------|
| 信号域 vs 成交域 | 方案 C（换算） | 前复权 MA 直接比 raw 分钟 | **X-01 critical**，修复中 | #200 X-01 |
| 止损触发 | bar H/L | bar close | **漏触发**，保守偏多 | #200 X-09 |
| 跳空穿越 | open 穿越按 open 成交 | ✓ 已有 | 无 | — |
| 除权日涨跌停 | 用除权参考价 | 用昨收 | **错判** | 未覆盖 |
| 分钟 MA 域 | 机构用日线 MA 换算，不在分钟线直接算 | s12 分钟逐 bar 算 | 正在修（X-01 = 方案 C） | — |
