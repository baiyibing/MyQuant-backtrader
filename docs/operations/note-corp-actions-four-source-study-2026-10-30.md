# corp-actions 四源冻结核对与独立扩样 — 2026-10-30

本研究检验 hithink 批量事件与 CNINFO v10 经济事实能否协作，在 Wind 在线不可用时推进离线研究。QMT 行情/价格复权权威保持不变，Wind #501 只作冻结历史对照。研究不接入消费者、不启用 C3、不代签 Owner、不合湖或切主源。

38 码固定样本和 240 码独立扩样均已完成。新样本解析 748 份公告，559 份获 adapter 接受，189 份拒绝；研究复核队列共 200 份，其中 11 份虽获接受仍存在数值/身份诊断问题。CNINFO v10 与已批准政策全程冻结，未利用本轮结果调规则后回写分数。接受率不等于准确率，当前未评定 economics-ready。

### 2.1 已核实的金额用途差异

`301266.SZ` 两份公告原文（来自冻结 fixture，text SHA256 与 C2 来源记录一致）明确把 hithink 对应数值用于**按总股本摊薄计算除权参考价**：

| 除权日 | CNINFO 经济候选现金 | hithink 现金 | CNINFO 送转合计 | hithink 送转合计 |
|---|---:|---:|---:|---:|
| 2025-05-30 | 0.1 | 0.0999998 | 0 | 0 |
| 2026-05-22 | 0.2 | 0.1999990 | 0.3 | 0.2999985 |

这不是仅靠舍入即可消除的经济语义差异。以按 lot 向下取整的 1000 股为例，`0.3` 与 `0.2999985` 分别算出 300 和 299 股。原值、用途及公告证据见 [semantic_findings.json](evidence/corp-actions-four-source-2026-10-30/semantic_findings.json)。不能仅补齐日期、放宽阈值或沿用 Wind 比较容差，就把 hithink 调整价格数值用于 entitlement。

两份冻结文本另做了观测式重放：调用原 v10 函数并断言字段/状态与归档一致，分别记录原文候选值、选择结果与上市日缺省前值。该两例的现金（及 2026 年转增）由已批准的 ROUND4 多值合并得到；它们是经济候选的**政策选择结果**，不能把原文多种分母数值抹成“原文只有一个金额”。见 [semantic_policy_trace.json](evidence/corp-actions-four-source-2026-10-30/semantic_policy_trace.json)。

另外三笔 hithink↔Wind 现金差异是 `000858/2026-07-16`、`300171/2024-07-12`、`600519/2026-06-26`：hithink 与 CNINFO 保存的数值相同，Wind 为四位小数。现行 CNINFO↔Wind ROUND4 政策照常保留，但不自动成为 hithink 接湖或消费的容差。

### 3.1 查询覆盖及身份诊断

240 码的四关键词查询已结束，保留 959 个有效响应页；逐页检查总数、列表、分页终止及缓存哈希，未发现结构异常。`002057.SZ` 的 `分红派息` 查询在限次重试后失败，整码标记查询不完整；不得将其他三个关键词的返回当作该码完整覆盖。覆盖以 `query_coverage.csv` 为准，进度文件中的空 `query_failures` 字段不作为证据。

13 个北交所样本共返回 61 份不同证券代码的公告，orgId 与请求一致，现有精确 secCode 过滤将其排除；这些是全部主题命中的文档数，包含预案/制度等，**不等于 61 个漏掉的分红事件**。例如 `920077` 返回旧代码 `836077` 的实施公告 `1220133984`。本轮不临时扩大身份映射，单列身份警告与来源元数据；后续须验证证券代码沿革、有效期及供应商各自的代码口径，同一 orgId 本身不授权跨代码合并。

标题规则另排除 1334 份去重文档，其中 174 份标题含更正/修订/取消/终止/延期/调整词，不全是相关经济事件。例如 `600081.SH / 1220816304` 的每股分配比例调整公告被排除，同时大量发行价/回购价调整亦应排除。归档排除清单用于审阅这一取舍；当前四关键词与标题规则不能证明修订/取消覆盖完整，更不能据此宣布 PIT 就绪。

### 3.2 已核实的复杂案例

- `000551.SZ / 1225385031`：派息句在 PDF 第 2 页末结束于“2026 年 7”，第 3 页页眉之后接“月 3 日”。原文支付日为 2026-07-03，冻结 v10 漏提后以 `missing_pay_date` 拒绝。这是已核实的跨页解析缺口，留待下一轮修订，本轮不改规则重算分数。
- `000088.SZ / 1220064023 → 1220070414`：原公告写支付日 2024-05-21，后续更正明确改为 2024-05-22。原件因支付日早于除权日进入复核，更正件也不自动消费；必须保留公告修订身份，不能按同日求和或跨公告补字段。
- `300243.SZ / 1220534844、1224145554`：股本变化、分配总额不变，公告实际执行的每股现金分别为 `0.0999985 / 0.0499999`，与 hithink 一致。冻结 v10 已识别 original/adjusted 两组候选，却先经 ROUND4 等价合并选成 `0.1 / 0.05`，两份均获 adapter 接受。这与 §2.1 的除权价格分母问题方向相反，是当前已批准精度政策下的原值损失；不将差异统一判作 hithink 错误，也不把 CNINFO 抽取结果当作独立真值。当前政策及分数不改，后续另刀评审“精确实施原值保存”与“对照容差”的分工。
- `600989.SH / 1225136155`：公告给中小股东 `0.4921`、大股东 `0.3906`；hithink 的 `0.42` 明确用于虚拟分派/除权参考价。Wind 保留两行 `0.4921 / 0.3906`，按日求和得到 `0.8827`，不代表任一类股东的每股权利；v10 选择 `0.4921` 对应中小股东。必须保留行身份及适用股东类别，不能以日聚合 parity 当经济真值。另两年同码差异保留待逐案核查，不由本例自动解释。
- `920018.BJ / 1225331866`：原文使用“权益登记日”，明确为 2026-06-01，v10 的 `record_date` 仍空；派现条款亦缺其要求的显式含税标记。该例说明北交所模板/金额依据覆盖缺口，不授权臆填缺失字段或把未明示口径改作已核实事实。

七份原文的五组定点检查见 [confirmed_case_notes.json](evidence/corp-actions-four-source-2026-10-30/confirmed_case_notes.json)。这些检查不能外推为整批抽取准确率，也不构成 Owner 签收。

## 4. 后续接入边界

经济候选应来自完整公告事件或已解析的修订链，hithink 提供发现与交叉核对。`(code, ex_date)` 是关联键，不授权拼接字段或修改事件身份；多公告/同日多事件、金额分母差异及不完整事件进入复核。

正式消费前仍需 Owner 独立签收原文事实/适配政策、覆盖与 PIT、修订身份、BT/qlib 接口。此次研究不签 OWNER_SIGNOFF，不启动 C3，不发布湖数据，不改变 live/paper 或 QMT 价格权威。生产采集和发布归 1.3，本仓保留研究证据与既有离线候选路径。
