## 关键语义结论

1. **阶梯无病理**：触发线 L(g) 单调不降，所有档间跳变向上（6%⁻→6%：+1.8%→+2.0%；15%⁻→15%：+2%→+15%；50% 内连续 kink 于 g=25%；50%→50%+：+30%→+35%；100%→100%+：+70%→+80%）。「涨 5.9% 回落 +1.7%」会触发（线 +1.77%）；真实接缝是 +1.77%~+2% 的普通 trailing 距离，非缝隙。到 -30% 止损的三条路（跌停链 defer/长期停牌跳空/px<cost 守卫区）v1 同样暴露——**v2 未引入新通道**。
2. **T+1 豁免 × peak 组合自洽**；「缝隙带」（peak∈[6,15) 阴跌）必穿越 +2% 线，无永洞。「反弹抬 peak 即按更紧线评估」（如 14.9%→15.1%）是全局底必然推论，非 bug，收录向量 #21。
3. **量级预警（切片 D 必报）**：v1 5 亿分钟 run **2611/4404=59.3% 平仓 lot 为 days==1 trail 退出（均值毛收益 +0.641%）**——T+1 豁免把六成交易的出口整体推迟一天以上，是小赢分布的系统性重塑；D 必须给 days==1 trail 占比前后对照，否则变化被净值终点掩盖。
4. **加仓语义**：lot 独立=记账独立**非风险独立**（同码 lot 完全正相关，5 lot 各 -30%=单码 -150 万）；同日 chase+pool 双计=两个独立信号各 100 万，与 P4 一致，**单码单日上限 2 笔**须声明；v1 实测池复hit率极低（已持跳过 33/全窗），增量小但口径先行。
5. **资金重估（先行估计）**：分钟侧 v1 峰值 207 只/1.84 亿 → v2 估 230-260 只 ≈ 2.3-2.6 亿（加仓 +33、T+1 豁免 +~12 并发），5 亿余量大；**日线侧才是风险**（v1 峰值 495 只/4.43 亿，v2 加仓+持有延长可能触顶）——D 双引擎都要测；若超：选项 (i) 提高 cash-total（需人裁）(ii) 单码上限参数 (iii) 接受 skip_cash+观测 (iv) name_budget 改单码累计（不建议顺手做）。
