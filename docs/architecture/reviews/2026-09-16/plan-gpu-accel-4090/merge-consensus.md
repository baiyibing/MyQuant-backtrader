## 关键问题：S0 会不会让 GPU 项目停下？

**会——至少回测线会停；整项目是否停取决于 chip 门。**

- D 烟测 minute **~90s ≪ 5min** → 若采纳 P1 回测阈值，**「回测 GPU」应判停**（与简报 §2.2「S0 判定门大概率判停」一致）。
- 现行 plan 的 AND 逻辑还要求「chip 非常跑」才整项目停：若无人声明频率、又未做**分钟** chip S0，则不应假装「整个 GPU 项目已科学关闭」，也不应假装「S2 已获墙钟许可」。
- **推荐人裁默认（H1+H2+H3）**：预裁关闭回测 GPU 线并归档该结论；S0 若保留则**只做分钟 chip**；若业务确认分钟全市场 chip 非日常 → 关闭 S2，GPU plan 整份归档。
