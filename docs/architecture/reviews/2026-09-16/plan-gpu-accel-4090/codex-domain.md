## 总判

- **核心主张成立**：4090 不进回测主循环；卖环是分支状态机；单次研究窗已是分钟级（D 烟测 ~90s）→ GPU 化回测无收益还背 parity 债。
- **最大 domain 风险不是「会不会碰成交核」**（A-R2/A-R7 已挡住），而是 **用错测量对象做出「立项 / 停项目」裁决**（facts 🔴1/🔴2），以及 **P1 门把两类负载绑死成单一停开关**（facts 🟡6）。
- 给定 D 烟测：**回测侧 P1 阈值（<5min）已预满足** → 「整个 GPU 项目因回测不够慢而停」在回测线上已可预裁；**唯一仍可能撑住 GPU 线的是「分钟全市场 chip 且常跑且小时级」**——而现行 S0② 测不到它。

## 异议 steelman（然后回复）

1. **「D 烟测是本机不是 4090，S0 仍要在 4090 复跑回测。」**  
   Steelman：硬件差可能改变墙钟。  
   Reply：4090 更快只会更强化「<5min」；复跑是可选确认，不是立项前置。不必挡预裁回测门。

2. **「日线全市场 chip 也很慢，测它也有价值。」**  
   Steelman：业务或许更常跑 resist 脚本。  
   Reply：有价值但属**另一产品线**；不能偷偷充当 S2（minute core）的 P2 证据（A-R8）。若业务真痛点是日线 resist，应改判定矩阵行，而不是沿用 minute GPU 故事。

3. **「先按 plan 原文跑 S0，错了再改。」**  
   Reply：会污染「research evidence」档案（合成数 / 错负载数被引用为加速比禁令的例外口子）。A-R5 精神是防未实测就上 GPU——用错测同样危险。
